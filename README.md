# 🔍 AI Code Reviewer

A smart, lightweight web application that reviews Python source code using **local static analysis** + **cloud LLM reasoning**.

Built as a university project. Runs on a standard laptop with 4 GB VRAM — no heavy local models required.

---

## ✨ Features

| Feature | How it works |
|---|---|
| **Syntax checking** | Python `ast` module — zero dependencies |
| **Linting** | pylint + flake8 |
| **Security scanning** | bandit |
| **AI explanations** | Groq / Gemini / OpenAI API |
| **Improved code** | Generated by the LLM |
| **Quality score** | 0–100 computed by AI (or estimated statically) |
| **Downloadable report** | Self-contained HTML file |
| **Static-only fallback** | Works without any API key |

## 🚀 Installation & Setup

### Step 1 — Clone or download the project

```bash
cd ai_code_reviewer
```

### Step 2 — Create a virtual environment (recommended)

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python -m venv venv
source venv/bin/activate
```

### Step 3 — Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4 — Configure your API key (optional but recommended)

```bash
# Copy the example file
cp .env.example .env
```

Open `.env` in any text editor and fill in your key:

```env
LLM_PROVIDER=groq
GROQ_API_KEY=your_actual_key_here
```

**Getting a free Groq key (takes 2 minutes):**
1. Go to https://console.groq.com
2. Sign up with Google or email
3. Click "Create API Key"
4. Copy it into your `.env`

> 💡 The app works **without** an API key — it just uses static analysis only.

### Step 5 — Run the app

```bash
streamlit run app.py
```

The app will open at **http://localhost:8501** in your browser.

## 🎮 How to Use

1. **Paste code** directly, or **upload a `.py` file**, or **upload a ZIP** with your project.
2. Click **Run Code Review**.
3. Browse the four result tabs:
   - **Issues** — all found problems, filterable by severity and category
   - **Improved Code** — AI-rewritten version of your code (requires API key)
   - **Recommendations** — actionable tips
   - **Download Report** — save as HTML, print to PDF from your browser

## ⚙️ Configuration Options

All options are in your `.env` file:

| Variable | Options | Default | Description |
|---|---|---|---|
| `LLM_PROVIDER` | `groq`, `gemini`, `openai` | `groq` | Which AI provider to use |
| `GROQ_API_KEY` | Your key | — | Required if provider=groq |
| `GROQ_MODEL` | Any Groq model | `llama-3.3-70b-versatile` | LLM model to use |
| `GEMINI_API_KEY` | Your key | — | Required if provider=gemini |
| `GEMINI_MODEL` | Any Gemini model | `gemini-1.5-flash` | LLM model |
| `OPENAI_API_KEY` | Your key | — | Required if provider=openai |
| `OPENAI_MODEL` | Any OpenAI model | `gpt-4o-mini` | LLM model |
| `MAX_FILE_SIZE_MB` | Integer | `5` | Max upload size in MB |
| `MAX_CODE_LINES` | Integer | `2000` | Max lines to accept |

## 🧪 Testing the App Without Writing Code

Use the **"Load sample buggy code"** button in the app.
The sample code has intentional bugs including:

- Hardcoded passwords (security)
- MD5 hashing (security)
- Pickle deserialisation (security)
- ZeroDivisionError risk (logic bug)
- SQL injection risk (security)
- Bare `except:` clause (bad practice)
- Unused imports and variables (style)
